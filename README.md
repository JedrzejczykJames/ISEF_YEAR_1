# JEV Spatial Risk Assessment Workflow

This repository contains an R Markdown workflow for spatial ecological risk assessment related to Japanese encephalitis virus (JEV). The workflow includes data preparation, West Nile virus (WNV) proxy processing, spatial analysis, ecological niche modeling, and suitability comparison.
