# JEV Spatial Risk Assessment Workflow

This repository contains an R Markdown workflow for spatial ecological risk assessment related to Japanese encephalitis virus (JEV). The workflow includes data preparation, West Nile virus (WNV) proxy processing, spatial analysis, ecological niche modeling, and suitability comparison.

## File

- `jev_spatial_risk_workflow.Rmd` — R Markdown source.


## Data and privacy

Input data are not included. Do not commit confidential, licensed, or personally identifying data, local machine paths, credentials, or API keys. Keep private datasets outside the repository and use relative paths or a local configuration file where practical.
